# Приведение расчёта к актуальному техническому приложению ЛЦТ 2026

За основу взято актуальное «Техническое приложение ЛЦТ» с приоритетом, подтверждённым ответом 16 в «Разъяснениях по вопросам ЛЦТ». Исходный PDF описывает более старую модель реконструкции существующей сети.

| Правило приложения | Код 1.9.5 |
| --- | --- |
| Расход и длина каждого непрерывного пути | `Network.flows`, `Network.lengthChecks`: группировка участков с постоянным расходом, затем проверка каждого корневого пути и повышение диаметра группы при превышении |
| 5 млн ₽ за каждый новый участок, входящий в существующую камеру | `ContestScore.existingChamberConnections` и `Evaluation`: подсчёт `children` этой камеры; новый узел на существующем трубопроводе оплачивается стоимостью камеры |
| C = стоимость новых труб + камер + врезок + штрафы; S = 70% C/25 млн + 30% Lнов/100 | `Evaluation`: отдельные поля строительства, штрафа, итога, сырых и округлённых баллов; реконструкция не входит в конкурсную оценку |
| Допустимый частичный маршрут | `Planner.calculate`: выбранный частичный вариант возвращается с числовым штрафом, исходными ID и статусом `PARTIAL_SOLUTION` |
| Ближайшая к точке граница ОКС | `BuildingAccess.Gate`: допустимыми остаются только ближайшие наружные стены; `SpatialRules` проверяет единственный прямой финальный подход |
| Специальные проходы | `SpatialRules`: проверка прямолинейности и угла дороги/трамвая к фактической границе в точке входа; `DepthPlanner`: разделение при изменении набора проходов |
| Минимальный GeoJSON и типы ссылок | `GeoJsonOutput`: допустимые четыре типа, ссылки на исходные `heat_chamber` и `oks_connection_point`, сохранение числовых ID |
| Базовый вход без существующего расхода, связей и диаметра камер | `Feature`, `InputValidator.validateContest`, `InputData.scenario`: необязательные расширенные данные не нужны для конкурсного расчёта; отдельный расширенный профиль сохранён |

Ограничения поиска и неиспытанные эксплуатационные требования перечислены в `VALIDATION.md`. Историческая версия 1.9.4 и её результаты имеют отдельную документацию и не считаются результатом повторной проверки по новым правилам.
