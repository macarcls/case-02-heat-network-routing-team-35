# Три назначения трасс · 1.9.3

При `routingStrategy=tree` и `variantLimit=3` выполняется поиск полной сети по общей оценке и, когда это нужно, дополнительные поиски по двум строительным показателям. Ограничения для всех проходов одинаковы: все вводы подключены, нет запрещённых пересечений и проверены диаметры, стены, глубина и стоимость. Каждый кандидат повторно оценивается по исходной общей шкале, поэтому `score` разных вариантов сопоставим.

| Вариант | Что снижается | Что сравнивать в отчёте |
| --- | --- | --- |
| 1. Лучший по общей оценке среди найденных | Привычный `balanced_score` | Стоимость, длина и сложность геометрии |
| 2. Проще земляные работы | `earthwork_index` | Условный объём траншеи, дополнительная глубина, спецпроходы |
| 3. Проще прокладка | `installation_index` | Повороты, число и суммарная величина изменений глубины, максимальная глубина, длина глубоких участков, индивидуальные узлы |

Условный объём траншеи равен сумме длина × средняя глубина × `(ширина трубной сборки + 1 м)` по участкам. Это сравнительный показатель, а не проектная ведомость. В данных нет категории грунта, грунтовых вод, откосов и типа крепления траншеи. В режиме «Только план» для сравнения принята общая глубина 3 м, профиль пока не рассчитан.

Второй вариант должен снизить свой показатель относительно первого минимум на 0,5%. Третий должен снизить показатель прокладки относительно **обоих предыдущих** минимум на 0,5%. Поиск дополнительно предпочитает пару, где земляные работы второго проще третьего; если такого компромисса не удаётся найти, это отмечается в `search.variantSelection.tradeoffNote`, а третий может улучшить оба строительных показателя. Не менее 6% новой трассы каждого выбранного маршрута должно проходить вне коридора 6 м вокруг каждого предыдущего маршрута; проверка симметрична. Если подходящей полной сети нет, программа показывает меньше трёх вариантов и записывает причину в `search.variantSelection`, не переименовывая похожие решения.

Параметры показателей имеют условные веса и показываются по компонентам. Поиск эвристический: первый вариант лучший только среди проверенных кандидатов, глобальный минимум и существование двух альтернатив не доказаны. Дополнительные проходы используют уже обученные веса для порядка поиска, не переобучая модель автоматически; готовые проверенные сети могут сохраняться как опыт для следующих расчётов.
