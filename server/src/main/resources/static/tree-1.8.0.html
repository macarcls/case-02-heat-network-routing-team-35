Обучение на разных участках

Общая модель учится на новых попытках по сохранённым участкам. Отдельные проверочные участки не участвуют в этом обучении. Новая модель применяется к новым участкам только после улучшения на проверке без ухудшения других результатов.

Нужны минимум 2 обучающих и 2 проверочных участка. Группы закрепляются автоматически.
