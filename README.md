# Теплотрасса AI · 1.9.5

Сервис строит новую тепловую сеть от существующей магистрали к точкам подключения, ищет общие ветви, обходит ограничения и рассчитывает цену и длину по актуальному техническому приложению ЛЦТ 2026. Нейросетевая политика меняет порядок проверки кандидатов; полная сеть проходит геометрическую и числовую проверку. Дообучение и сохранение опыта доступны в интерфейсе.

## Что исправлено по сверке с ТЗ

- Ду подбирается по расходу и длине **каждого непрерывного пути**; параллельные ветви не складываются, длинный участок может потребовать несколько ступеней Ду.
- Конечный прямой подход к точке ОКС проходит через ближайшую к ней наружную стену. Допускаются углы поворота до 90°; специальные проходы прямые, дорожный угол проверяется по реальной границе.
- Каждый новый участок в существующей камере добавляет 5 млн ₽. `construction_cost` включает новые трубы, камеры и врезки; `calculated_cost` добавляет штрафы за неподключённые точки. Именно он участвует в итоговом `score` вместе с длиной **новой** сети.
- Выход содержит только `heat_network`, `heat_chamber`, `technical_node`, `variant_summary`, с исходным типом ID и совпадающими геометрическими концами участков. При отсутствии полной сети возвращается проверенный частичный результат со штрафом.
- Конкурсный расчёт принимает базовый формат без расхода существующей сети, направления `upstream_object_id` и диаметра существующих камер; необязательная инженерная оценка использует расширенные поля.

Поиск эвристический, глобальный минимум не доказан. Старые расчёты версии 1.9.4, включая 17/17 и S=13,4576, **не проходят** новые правила ближайшей стены и не подтверждают результат этой сборки. Текущие проверки и границы подтверждения: [VALIDATION.md](VALIDATION.md). Подробности исправлений: [docs/APPENDIX_COMPLIANCE_1.9.5.md](docs/APPENDIX_COMPLIANCE_1.9.5.md).

## Запуск

Распакуйте архив целиком. Для обновления используйте прежнее имя Compose-проекта, чтобы сохранить тома и базу, и перенесите старый `.env`, если меняли параметры БД:

```powershell
$env:PORT = "8082"
docker compose -f .\docker-compose.yml -p teplotrassa-tree151 up -d --build
```

Откройте <http://localhost:8082/tree-1.9.5>. Если Docker Hub отвечает по HTTP вместо HTTPS при запросе токена, Docker-сборка прервётся до компиляции проекта: проверьте настройки прокси и доступ Docker к `auth.docker.io`. Для запуска готового JAR вне Docker нужны Java 11 и PostgreSQL, параметры базы указаны в `server/src/main/resources/application.yml`.

Версия сервера `1.9.5-contest-compliance`, buildId `contest-compliance-20260928-r2`. Интерфейс проверяет их совпадение с сервером. История алгоритма и прежние экспериментальные результаты остаются в `docs/`, но не заменяют проверку текущего расчёта.
