Ближайшая стена — предпочтение по прямому расстоянию от допустимого окна стены до конкретной точки подключения ветви к рассчитанной сети. Полная оценка одновременно учитывает препятствия, габариты трубы, углы, стоимость и общие участки. Строгое совпадение с геометрически ближайшей стеной не гарантируется: в отчёте для каждого потребителя записаны расстояния до выбранной и ближайшей наружных стен. Точное место и конструкция прохода через стену уточняются инженером после расчёта.

В восстановленном сценарии дополнительная стадия проверила 10 маршрутов к стенам и приняла 2 улучшения полной сети. В новом расчёте она не нашла дополнительно подходящих более близких маршрутов; основной поиск уже выбрал стены при построении сети. Во всех выданных вариантах отчёт отмечает `buildingEntriesValid=true`, `wallSelectionPolicy=network_facing_exterior_wall` и сохранение исходных вводов. В двух режимах выдано по 3 полных варианта.

Все 50 основных Java исходников компилируются для Java 11. Изолированный запуск шести проверок скомпилированных исходных тестов подтверждает выбор стены с противоположной стороны здания, допустимость другой стены вместо ближайшей к исходной точке, сохранение адреса потребителя и старую проверку направления вдоль фасада. Синтаксис нового интерфейса проверен через `node --check`. Полный `mvn test`, сборка Docker и браузерная проверка в этой среде не выполнялись; проект содержит исходники и Dockerfile для обычной сборки. Стоимость специальных узлов из предыдущего исправления фасадов по-прежнему требует инженерной проверки и не включена в денежную смету.
