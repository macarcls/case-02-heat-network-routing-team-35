# Проверка TREE 1.6.0 GROUPS — 2026-09-22

Сборка `1.6.0-tree-groups`, buildId `tree-groups-20260922-r1`, UI `/tree-1.6.0`.

## Выполнено

- Полный набор регрессионных тестов: 140 пройдено, 6 opt-in пропущено. Затем отдельный тест большой карты пройден; суммарно 141 различных тестов пройдено, 5 opt-in не запускались. Ошибок и падений нет. Подробности — `test-results.json`.
- Проверено восстановление снимка сети и отсутствие перезаписи существующих узлов при создании новых ID.
- Проверены группы и единая врезка, сохранение более дешёвой сети с несколькими врезками, отложенное подключение дальнего ввода после роста дерева.
- Проверено уменьшение скорости и максимального изменения весов после отклонения модели, сохранение множителя при перезапуске, сохранение обучающих сравнений при использовании кеша.
- Chromium: два реальных расчёта, восстановление модели/примеров/лучших сетей, ширины экрана 1440 и 390, отсутствие ошибок страницы и горизонтального переполнения, переход со старого `app.js`, блокировка расчёта с сервером другой сборки, версии JSON/GeoJSON и имён файлов. См. `ui-check.json`, `ui-tree-report.json`, `ui-tree-repeat-report.json` и PNG.
- Готовый JAR проверен по CRC всех записей. Номер сборки подтверждён живым API. Проверка Docker/PostgreSQL и PowerShell здесь не выполнялась: сервер проверен на Java 11 с тестовым H2.

## Контрольный пример интерфейса

Исходный score перед отдельной групповой перестройкой: 2.384213732; после: 2.312865946. Улучшение 2.9925%. Полное подключение двух исходных вводов, одна врезка. Это результат группового этапа, не доказательство выигрыша от обучения модели. Весь первый расчёт — 1.201 с на проверочном стенде.

## Большая карта: 17 вводов

Файл `examples/supplied.geojson`, SHA-256 `07921d7740c0297a63111846d4b77dfb6ccb33da65ffd7ccb14c5b2d786dd7d0`. Глубина, сценарная загрузка 50%, шаг 20 м, параметры 5/3/2/8; обучение выключено; продолжение сохранённой сети, группы и сравнение общей врезки включены.

Старт — доступная геометрия сохранённого варианта 1.5.0 со score 23.618477814. Геометрии пользовательского более позднего результата 23.516770310 в прикреплённом JSON-отчёте нет, поэтому этот тест не является воспроизведением именно того состояния опыта. В работающем проекте используются его собственные сохранённые сети; тестовый seed автоматически не загружается.

Группы пересмотрены на разных частях карты. Найденные полные замены оказались хуже исходной по общей оценке; неполные отклонены. Из двух проверенных мест единой врезки полная сеть не найдена. Лучшие попытки подключили 16 из 17 вводов; отказы включают ввод 10 с закреплённой ближайшей стеной. Это не доказательство невозможности одной врезки в другом месте или с другим порядком.

Исходная полная сеть сохранена без ухудшения. Выдан один вариант, поскольку тест загрузил один сохранённый вариант и не нашёл новых лучших сетей. Рабочий проект сохраняет до трёх своих лучших сетей.

Независимая проверка Python/Shapely/PROJ пройдена: исходные координаты концов, 17 закреплённых ближайших стен, запрет транзита через здания, отступы, отсутствие неузловых пересечений и циклов, расходы и DN, глубины, суммы стоимости и длины, повороты и формула score. См. `independent-check.json`.

Время нельзя напрямую сопоставлять с пользовательскими 66 минутами: здесь продолжалась сохранённая сеть без обучения, а в том прогоне были более широкие параметры и четыре полных поиска.

## Повторение

Из каталога `server`:

```sh
mvn test
mvn -Dtest=TreeGroupsSuppliedTest -DtreeGroupsSupplied=true -DtreeSeedGeo=../validation/tree-groups/seed-1_5_0.geojson test
```

Из корня проекта, после установки `validation/requirements-check.txt`:

```sh
python validation/verify_nearest_turns.py --output-name tree-groups/supplied-groups --report-name tree-groups/independent-check.json
```

Состояние опыта пользователя в архив не включено. В README описано обновление с сохранением прежних томов и имени Compose-проекта.
